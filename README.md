# Governed Curation Standard

**Human-authorized, AI-assisted: a standard for governing the description of cultural heritage collections.**

Version 0.1 publishes here in October 2026, with a DOI. Until then this repository holds the standard's citation scaffolding.

The standard states what any implementation must be able to prove when AI describes a collection: a Collection Charter the institution writes and holds; explicit human decisions at review gates; frozen artifacts and an append-only run ledger; decision records that are numbered, attributed, and kept; and partner authority over what is adopted and published. It deliberately does not specify models, prompts, vocabularies, or thresholds.

Author: Mark Tebeau, Arizona State University. License: CC BY 4.0. First implementation: ARCADE (https://arcadecuration.org), which the standard does not require.
